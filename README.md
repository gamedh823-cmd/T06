# 플랜두씨 다이어리 1 — 내 계획과 실제를 담는 앱

Plan(계획) → Do(실제로 한 일) → See(돌아보기)가 하나로 이어지는, 로그인 없는 다이어리 앱입니다. 자료는 Supabase(Postgres) 서버 데이터베이스에 저장되며, 새로고침해도 그대로 남습니다.

- 실행: [https://plan-do-see-three.vercel.app](https://plan-do-see-three.vercel.app) 접속하면 바로 사용할 수 있습니다 (별도 설치·서버 불필요, 로그인 없음).
- 검증 방법: [검증안내서.md](검증안내서.md)
- 통과 기준 체크리스트: [체크리스트.md](체크리스트.md)
